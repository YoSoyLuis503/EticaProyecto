# El Campamento de los Sueños ⛺🌟

Prototipo web educativo e interactivo hecho con **Vue 3 (`<script setup>`)** y **Tailwind CSS**, dirigido a niños de **5 a 7 años**, sobre el **Derecho a Jugar y Descansar**.

## Ejecutar localmente

```bash
npm install
npm run dev
```

## Verificar y compilar

```bash
npm test
npm run build
```
